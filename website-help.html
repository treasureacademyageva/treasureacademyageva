What went wrong?

The report uses only these broad choices. It does not copy typed details, raw searches or other form values.

Diagnostics include only page category, screen-size group, browser family, theme and recent action categories. They never include names, phone numbers, form values or raw search text.

Before reporting

  • Try meaning-aware search using one or two simple words.
  • Browse the website guide.
  • For an urgent school question, contact the office.
  • For a child-safety concern, use the safeguarding route.

Your privacy

The website passes only the broad categories and, if selected, a safe diagnostic code to the Request Centre in this browser session. It never copies typed details or raw search words.

No report is sent automatically. Review the request, add only details you choose, then submit it to receive a private tracking code.
