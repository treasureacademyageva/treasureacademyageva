## Defects found and closed during acceptance

- Replacement Pages initially created a second H1 where the fixed hero already owned the H1. The renderer now updates the existing hero heading and summary.
- The generated route audit initially failed to understand clean canonical paths. It now resolves clean routes through the reviewed route registry.
- The Page Search projection initially excluded Page content published through an approved core slot. It now indexes only fixed Page/core-slot destinations.
- The Website Help handoff used an obsolete session key. It now uses the current Request Centre prefill contract.
- The WhatsApp confirmation row changed its hidden attribute but not its display class. Both states now change together.
- A content link relied on colour alone. Reviewed content links now retain a visible underline.
- The desktop header overflowed at exactly 960 pixels after breakpoint consolidation. The 960–1120 layout now uses a compact reviewed header.
- Stale browser fixtures for Request Centre routing, fee wording, News fallback and header dimensions were updated to the current reviewed contracts.
