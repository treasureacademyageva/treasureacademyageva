# Owner Brand Evidence Checklist

Use this checklist before an image, logo, social profile or document is presented as official Treasure Academy material. Do not send passwords, pupil records, payment details or other private records with this checklist.

## 1. Approved school identity

- [ ] Confirm the public name: **Treasure Academy, Ageva**.
- [ ] Confirm the legal name: **Treasure Academy Ageva Limited**.
- [ ] Confirm company number **RC 9634403**.
- [ ] Confirm the motto: **Our God is able**.
- [ ] Supply the approved master logo as SVG or a large transparent PNG.
- [ ] Name the person who approved the logo and the approval date.
- [ ] Confirm whether the restored artwork that says “Treasure Kiddies” is retired, historical or still authorised.

The public website currently uses a neutral **TA** text mark. The mismatched restored mark is withheld from public pages until the owner supplies the approved master.

## 2. Photograph approval sheet

Complete one row per photograph.

| File name | Date taken | Place/activity | Photographer/source | People shown | Parent/staff consent confirmed? | Approved public placements | Accurate alt text | Owner approver and date |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |

Recommended first set:

- campus exterior and entrance;
- one classroom image without exposed private records;
- one supervised learning activity;
- one current sports or cultural activity;
- one current event or announcement image.

Do not supply screenshots of private records, unlicensed images, unrelated schools, images with uncertain consent or images downloaded from random websites.

## 3. Verified social profiles

For each official profile, provide:

- exact HTTPS profile URL;
- platform;
- profile owner/administrator;
- proof the school controls the profile;
- date checked;
- approval to publish the link.

No profile will be added to structured data or the public website until the URL and ownership are verified.

## 4. Public documents

For each admissions guide, fee schedule, calendar, uniform list or prospectus, provide:

- approved file;
- document owner;
- effective term/session;
- review/expiry date;
- intended public page;
- confirmation that it contains no pupil, applicant, staff, bank-account or other private record that should not be public.

Payments use manual bank transfer or the physical school-office POS after office confirmation. A public document must not create a checkout, card-data form, WhatsApp payment-evidence workflow, browser receipt or unverified payment-success claim.

## 5. Current school information

Confirm or update:

- mission and vision;
- current academic programmes and class availability;
- current activities and clubs;
- upcoming events and announcements;
- current admission process and documents;
- current fee guidance and payment-verification process;
- school hours and visit arrangements;
- verified phone, WhatsApp, email and address;
- parent-help process.

## 6. Handoff

An owner or developer can update `assets/data/brand-assets.json` only after the evidence above is complete. The build validates verified assets and fails closed when required authority, consent, date, placement, dimensions or source files are missing.
